# Appendix E — Evidence register

Evidence is collected by `scripts/collect-evidence.sh` and stored outside the
source history. Each run has a UTC timestamp and a `manifest.json` with the
command, input URL and result status. A skipped artifact is not treated as a
passing performance or availability claim.

| Artifact | Collector | Default status in a clean clone |
|---|---|---|
| Mobile and desktop role screenshots | `frontend/e2e/evidence-screenshots.spec.ts` | not collected until role accounts are configured |
| JaCoCo report and test scenario result | Maven + evidence runner | JaCoCo HTML, Surefire XML and `test-scenarios.tsv` when backend dependencies are available |
| Query timings and `explain()` output | `KpiPerformanceEvidenceIT` | generated by the explicit integration run |
| k6 summary | `load-tests/mixed-scenario.js` | not collected until a base URL is supplied |
| Grafana panels | `scripts/capture-grafana.sh` | not collected until Grafana credentials are supplied |
| Restore-drill log | `scripts/backup-restore-drill.sh restore` | not collected until a backup archive is supplied |
| OpenAPI JSON | `GET /v3/api-docs` | not collected until the API is reachable |

The report can therefore be built from a clean clone without fabricating
runtime facts. The defence run should attach the collected manifest and show
the corresponding screenshots/logs.
