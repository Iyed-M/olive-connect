# Vergers

Cette page contient les vergers de l’agriculteur connecté.

- Utilisez Ajouter un verger pour définir la position et saisir le détail des parcelles.
- Le navigateur peut demander votre position pour centrer la carte sur vous.
- Le serveur recalcule les totaux et refuse les variétés ou les positions invalides.

Sur un écran de 360 px, remplissez une section à la fois et gardez l’action principale près du bas du formulaire.
