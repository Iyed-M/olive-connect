# OliveConnect help

Use the question-mark button at any time to get help for the page you are viewing.

- The side navigation is available on larger screens.
- On a phone, the same navigation is the bar at the bottom of the screen.
- Use the profile menu to replay the guided tour.

If an action fails, keep the message visible and retry after checking the connection. The API remains the source of truth for permissions and business rules.
