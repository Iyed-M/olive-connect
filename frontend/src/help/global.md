# Aide OliveConnect

Utilisez à tout moment le bouton point d’interrogation pour obtenir de l’aide sur la page affichée.

- La navigation latérale est disponible sur les grands écrans.
- Sur téléphone, la même navigation se trouve dans la barre en bas de l’écran.
- Utilisez le menu du profil pour revoir la visite guidée.

Si une action échoue, gardez le message affiché et réessayez après avoir vérifié la connexion. L’API reste la référence pour les permissions et les règles métier.
