# Logistique

Les ouvriers, les équipements, les créneaux du calendrier et les approvisionnements se gèrent depuis cette section.

- Vérifiez la disponibilité avant d’affecter une ressource à une tournée.
- Utilisez le calendrier pour consulter les réservations et les indisponibilités d’une ressource.
- Gardez à jour l’état des équipements et les stocks pour que les planificateurs voient des disponibilités fiables.
