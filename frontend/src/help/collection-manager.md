# Gestion de la collecte

Utilisez la file des demandes pour examiner les demandes de récolte et les pages de planification pour préparer les tournées de collecte.

- Vérifiez la priorité, la fenêtre souhaitée et la maturité avant de planifier.
- Traitez les messages de conflit et de modification obsolète comme des actions à mener : rechargez les données et choisissez une autre ressource ou un autre horaire.
- Le tableau des alertes garde les incidents terrain visibles pendant que vous coordonnez l’équipe de collecte.
