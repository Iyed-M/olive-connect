# Administration et exploitation

Les pages d’administration gèrent les utilisateurs, les inscriptions, les imports, les paramètres et les vues de toute la coopérative.

- Désactivez un utilisateur plutôt que de le supprimer afin de conserver son historique.
- Lisez les messages de validation et de conflit avant de relancer une action d’administration.
- En production, gardez les pages intranet à l’intérieur du réseau protégé.
